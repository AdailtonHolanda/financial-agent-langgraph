# Git Setup Instructions

## Inicializar e fazer push para o repositório

```powershell
# Inicializar repositório Git
git init

# Adicionar todos os arquivos
git add .

# Fazer commit inicial
git commit -m "Initial commit: Financial Agent with LangGraph, RAG, and Terraform"

# Adicionar remote
git remote add origin https://github.com/AdailtonHolanda/tech_challenge.git

# Fazer push
git branch -M main
git push -u origin main
```

## Verificar antes do push

Certifique-se de que o `.gitignore` está correto para não subir arquivos sensíveis:
- `.env` (credenciais)
- `*.tfstate` (estado do Terraform)
- `venv/` (ambiente virtual)
- `pdfs/` (PDFs baixados)
- `faiss_index/` (índice local)
- `lambda_deployment.zip` (pacote de deploy)

## Após o push

O repositório conterá:
- Código-fonte completo (`src/`)
- Infraestrutura Terraform (`terraform/`)
- Scripts de deploy (`scripts/`)
- Notebook de demonstração (`demo_notebook.ipynb`)
- Documentação completa (`README.md`)
- Análise de requisitos (`REQUIREMENTS_ANALYSIS.md`)
